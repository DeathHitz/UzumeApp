# Project Uzume
## 1. Meaning
Uzume (Ame no Uzume) is the Shinto goddess of dawn and revelry. I chose this as the project name, because this project is supposed to
be a learning experience and isn't meant to be that serious yet. Also, it kinda sounds cool.

## 2. Project Goal
Uzume is supposed to be te core of a diverse, modular data handling network.
Core Features that will be implemented are:
- Support for other custom Modules
- A (React)frontend that is controlled via JSON backend instructions  
  - including custom theme support via modules

## 3. Getting started
1. run `git submodule update --init --recursive`
2. use `make up` or `docker compose up` to start the app dev environment
3. use `make down` or `docker compose down` do stop the app

For Development, you should also install all maven dependencies locally. However, to start the App you only need docker.
