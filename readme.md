# Project Uzume
## 1. Meaning
Uzume (Ame no Uzume) is the shinto goddess of dawn and revelry

## 2. Project Goal
Uzume is supposed to be the core of a diverse, modular data handling network.

## 3. Getting started
1. run `git submodule update --init --recursive`
2. use `make up` to start the app dev environment

For Development you should also install all maven dependencies locally. However to start the App you only need docker.
